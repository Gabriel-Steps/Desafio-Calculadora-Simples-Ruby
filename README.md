# 🧮 Calculadora Simples em Ruby

Este projeto é uma **calculadora simples em Ruby**, executada via terminal, que permite realizar operações matemáticas básicas de forma interativa.

## 📌 Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão (com validação para divisão por zero)
- Opção para sair do programa

O programa roda em um **loop contínuo**, permitindo que o usuário realize várias operações até escolher sair.

## 🛠️ Tecnologias Utilizadas

- Ruby

## ▶️ Como Executar o Projeto

1. Verifique se o Ruby está instalado:
```ruby
ruby -v
```
2. Clone o repositório:
```ruby
git clone https://github.com/Gabriel-Steps/Desafio-Calculadora-Simples-Ruby.git
```
3. Acesse a pasta do projeto:
```ruby
cd Desafio-Calculadora-Simples-Ruby
```
4. Execute o programa:
```ruby
ruby desafioCalculadora.rb
```
